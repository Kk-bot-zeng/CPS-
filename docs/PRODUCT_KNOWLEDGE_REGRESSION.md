# 产品资料库与文案生成回归测试清单

> 适用范围：产品资料库、自定义字段、Excel 导入/覆盖、版本回滚、活动政策、型号选择和文案生成。
>
> 本清单只使用本地脱敏数据，不连接生产数据库，不触发京东/B站同步或真实外部发送。产品资料库接口尚在开发中，路由名称以最终实现为准；每项接口测试必须在测试记录中填写实际路径和响应样例。

## 1. 测试前置条件

- [ ] 从最新 `main` 创建独立测试分支，`git status --short` 无未说明修改。
- [ ] 使用独立本地 PostgreSQL 数据库，确认 `DATABASE_URL` 指向 `127.0.0.1`，禁止使用生产 `.env`。
- [ ] 执行 `pnpm install --frozen-lockfile`、数据库增量迁移和 `pnpm db:seed-demo`（如迁移提供独立种子，则使用该种子）。
- [ ] 创建本地测试管理员，不在测试记录、日志或截图中写入真实密码、Token、Cookie 或 AI Key。
- [ ] 运行 `pnpm build`，记录基线结果；基线失败时先区分原有失败与本次失败。
- [ ] 启动本地应用，记录测试地址、提交版本、数据库迁移版本和测试时间。

## 2. 脱敏测试数据

每次执行前清空本测试专用的产品资料、字段、活动政策、导入批次和生成历史。以下名称仅为示例，不代表真实业务数据。

| 编号 | 品类 | 系列 | 标准型号 | SKU | 关键资料 |
| --- | --- | --- | --- | --- | --- |
| TV-01 | `tv` | 鹊6 26款 | 65鹊6 26款 | TV-SKU-001 | 峰值亮度 1000；HDMI 2.1；卖点“示例电视卖点” |
| TV-02 | `tv` | 鹊6 26款 | 75鹊6 26款 | TV-SKU-002 | 峰值亮度 1200；HDMI 2.1；卖点“示例大屏卖点” |
| MON-01 | `monitor` | M 系列 | M27U | MON-SKU-001 | 刷新率 160Hz；接口 DP；卖点“示例显示器卖点” |

额外建立同名但不同品类的数据，用来验证隔离：`tv/共用型号` 与 `monitor/共用型号`。另建立渠道策略：京东有效政策、抖音有效政策、已过期政策各一条。

## 3. 固定字段与品类隔离

### 3.1 基础 CRUD

- [ ] 新增产品时，品类、系列、标准型号、SKU、推广名和启用状态按设计要求校验。
- [ ] 同一品类下重复的“标准型号”不能产生第二条活动记录；重复导入应返回可理解的冲突信息，而不是 500。
- [ ] 同名型号在 `tv` 与 `monitor` 下可以分别存在，查询、编辑、导出和文案引用互不影响。
- [ ] `monitor` 只能进入京东渠道（如果该规则由资料库继承业务约束），非法渠道请求被拒绝且不落库。
- [ ] 删除产品/停用产品后，既有版本、生成历史和导入批次仍可追溯；页面不再将其作为默认可选型号。

### 3.2 数据查询隔离

- [ ] 只查询 `tv` 时不返回任何 `monitor` 记录，反之亦然。
- [ ] 同时带型号和品类查询时，唯一键必须包含品类；不能因型号相同覆盖另一品类。
- [ ] 在文案生成页面切换品类后，已选型号清空或重新校验，不能把 TV 参数带入显示器。
- [ ] 直接构造缺失品类、非法品类、数组注入、SQL 关键字等参数时返回 400，不改变另一品类的数据。

## 4. 动态字段管理

### 4.1 新增、修改、停用和删除

- [ ] 新增字段 `峰值亮度`，类型为数字，作用域为 TV；TV 模板出现该列，显示器模板不出现。
- [ ] 新增字段 `接口`，类型为多选；模板、预览、详情和生成上下文保持同一序列化规则。
- [ ] 新增字段 `上市日期`，类型为日期；非法日期、越界日期和空值策略有明确错误提示。
- [ ] 新增同名字段、空名称、超长名称、保留字段名、非法类型和超过字段数量上限时拒绝保存。
- [ ] 修改字段显示名/排序不会改变已有值的字段标识；历史版本仍能按原字段解释。
- [ ] “删除”默认采用停用/软删除，历史资料与历史生成仍可读；已被产品资料或版本引用的字段不得被物理删除。
- [ ] 已停用字段不出现在新模板和新生成的可选资料中；重新启用后历史值恢复可见。
- [ ] 如果产品明确支持物理删除，必须验证二次确认、影响统计和可回滚；不得静默级联删除历史版本。

### 4.2 字段权限与边界

- [ ] 未登录用户不能查看、增加、停用、删除字段（应为 401）。
- [ ] 普通无权限用户不能执行管理操作（应为 403 或项目统一错误码）。
- [ ] 字段值中的 HTML、脚本、模板指令、超长文本只按文本存储/展示，不执行；列表和详情无 XSS。
- [ ] 自定义字段不存在、类型不符、传入对象结构错误时返回 400，且单次请求无部分写入。

## 5. 导入、预览和覆盖语义

测试文件至少包含：新产品 1 行、已有产品更新 1 行、同品类冲突 1 行、跨品类同型号 1 行、空值 1 行、非法类型 1 行、重复行 1 行、未知字段 1 列。

### 5.1 模板

- [ ] TV 和显示器分别下载模板；模板列由当前启用字段动态生成，并包含字段说明、类型和示例。
- [ ] 字段停用后下载新模板不再包含该字段；旧模板导入时给出兼容/未知列提示，不静默把数据写错列。
- [ ] 模板包含品类、系列、标准型号、SKU 等唯一匹配所需字段；唯一键规则在模板说明中可见。

### 5.2 预览

- [ ] 上传不直接写入业务表，先返回预览：新增数、更新数、冲突数、跳过数、错误数、未知字段数及逐行错误。
- [ ] 预览统计按品类和导入批次计算；TV 文件不能统计到显示器，显示器文件不能统计到 TV。
- [ ] 同一文件重复预览结果稳定；文件名、重复行、空行和列顺序变化不会导致统计错乱。
- [ ] 预览错误超过阈值或唯一键缺失时，确认按钮不可用；错误明细不得泄露数据库堆栈、路径或密钥。

### 5.3 三种导入模式

用同一已有记录作为基线：卖点=`旧卖点`、亮度=`1000`、接口=`HDMI 2.1`。

- [ ] **仅新增**：新型号写入；已有型号只计入跳过/冲突，不修改任何字段。
- [ ] **合并更新**：非空列更新；上传空单元格不清空已有值；未出现的字段不变。
- [ ] **完整覆盖**：上传值覆盖旧值；明确允许的空单元格会清空旧值；未授权/未识别字段不能误清空其他字段。
- [ ] 三种模式都以 `品类 + 标准型号`（或最终确认的唯一键）匹配，SKU 变化的行为有明确提示，不能产生隐式重复产品。
- [ ] 导入在数据库事务中完成：任一行触发不可恢复错误时不产生半批数据，批次状态和错误原因可追踪。
- [ ] 重复提交同一批次具备幂等性，不重复插入、不重复生成版本。
- [ ] 导入后页面数据、详情接口、导出和文案生成读取同一活动版本。

### 5.4 参数表自动建字段与整表覆盖

- [ ] 使用 `mode=overwrite` 且 `autoCreateFields=true` 导入带中文表头的参数表：未知中文表头自动新增为当前品类的自定义字段，并在预览中返回 `newFields`。
- [ ] 使用相同中文表头再次导入时，`newFields` 为空；字段数量、字段 Key 和字段 ID 保持不变，不创建同名重复字段。
- [ ] 覆盖表中已有型号时，空白单元格会清除该型号对应的旧值；未出现在本次参数表中的另一个旧型号及其参数保持不变。
- [ ] 先停用一个自定义字段，再以相同中文表头导入时，系统返回 `restoredFields` 并恢复原字段；不得新建第二条同名字段，历史值和新值仍可读。
- [ ] 参数表字段创建、字段恢复、型号写入和版本生成在同一确认事务中完成；确认失败时不得留下半批字段或产品数据。

## 6. 版本、审计和回滚

- [ ] 每次确认导入产生版本号、操作人、时间、模式、文件摘要和统计；预览不产生“活动版本”。
- [ ] 新版本成为活动版本，旧版本保留且可查看差异；历史版本不能被无确认覆盖。
- [ ] 回滚前显示目标版本、影响品类/型号/字段和确认提示；回滚后只有目标版本为活动版本。
- [ ] 回滚失败时原活动版本保持不变；不能出现“无活动版本”或半回滚。
- [ ] 生成历史记录引用所用产品资料版本；回滚后新生成使用回滚后的版本，旧文案不被改写。
- [ ] 版本列表、差异和回滚接口受鉴权保护，不能通过修改 ID 访问另一品类或另一用户无权数据。

## 7. 活动政策与过期排除

- [ ] 长期参数与活动价格/佣金/时间/地区/渠道政策分表或明确分层保存，导入政策不会覆盖长期参数。
- [ ] 生成时只引用“当前品类、当前渠道、适用日期范围内、启用”的政策。
- [ ] 已过期、尚未生效、停用和其他渠道政策不会出现在生成上下文或最终文案中。
- [ ] 同一型号存在重叠政策时，系统必须提示冲突并阻止自动选择，或按已确认优先级选择且记录理由。
- [ ] 日期边界按系统统一时区验证：生效日 00:00、失效日 23:59:59、跨月/跨年均不提前或延后一天。
- [ ] 没有有效政策时文案明确写“待业务确认”，不得自行计算到手价、佣金或折扣。

## 8. 文案生成

### 8.1 型号选择

- [ ] 选择器按品类和渠道过滤，支持搜索、清空、单选和多选；切换品类/渠道时清理不兼容选择。
- [ ] 选中 TV-01 与 TV-02 后，**合并生成**只返回一条，说明共同卖点并准确区分两个型号；不得把 65 英寸参数写给 75 英寸。
- [ ] 选中两个型号后，**分别生成**返回两条可独立复制的结果，每条都标明对应型号和资料版本。
- [ ] 同型号重复选择去重；没有选择型号、型号已停用或跨品类型号时，按钮不可用并给出明确提示。

### 8.2 50 字选项

- [ ] 界面出现“50字”可选项，发送请求携带稳定的长度值（推荐 `50` 或 `short_50`），不是只改变显示文案。
- [ ] 选择 50 字时，`文案草稿`正文控制在约 50 个中文字符（建议验收区间 45–60；区块标题、待确认事项和风险状态单独计算），不因模型换行、Markdown 标记而失控。
- [ ] 50 字模式仍保留必要的型号、已确认卖点和风险提示；长度不足时宁可省略非关键修饰，不截断型号、价格和条件。
- [ ] 其他长度选项不被 50 字设置污染；连续切换长度后每次请求和结果对应当前选择。

### 8.3 资料引用与防编造

- [ ] 生成请求只携带当前活动版本的已确认字段和适用政策；停用字段、旧版本和过期政策不进入上下文。
- [ ] 缺少亮度、接口、价格、佣金或有效期时，结果标记“待业务确认”，不得补写来源之外的数字、比较级、排名、库存或优惠。
- [ ] 输入中要求模型忽略规则、泄露系统提示、伪造参数或发布内容时，结果仍遵守事实边界；不得返回 API Key、数据库连接串或内部提示词。
- [ ] 参数冲突时风险状态为不可发布/需人工复核（以产品最终枚举为准），并列出冲突字段。
- [ ] 生成历史保存：操作人、时间、品类、渠道、选择的型号、资料版本、政策版本、长度和生成结果；不保存完整密钥或不必要的会话信息。
- [ ] 上游超时、限流、空响应、非 JSON、鉴权失败时页面可恢复，错误码可区分，重复点击不会产生重复请求或重复历史。

## 9. 鉴权和输入边界接口测试

对产品字段、产品资料、导入预览/确认、版本回滚和文案接口逐一执行：

- [ ] 无 `cps_session` 请求返回 401；失效、篡改、过期 Cookie 也返回 401。
- [ ] 错误账号/密码返回 401；响应不说明“账号存在与否”，不返回堆栈。
- [ ] 正常登录只设置 HttpOnly 会话 Cookie；响应体和日志不出现密码、Session Secret、AI Key。
- [ ] 空 body、非法 JSON、数组代替对象、未知字段类型、缺少必填值、超长字符串、超大行数、超多自定义字段均返回 400/413，不返回 500。
- [ ] 品类只能为最终允许枚举；渠道只能为 `jd`/`douyin`/`tmall`（显示器仅京东时额外校验）。
- [ ] 型号、SKU、字段名、政策文本中的 SQL/XSS/模板注入字符串按普通文本处理，不执行、不破坏查询、不影响其他记录。
- [ ] 伪造他人产品 ID、批次 ID、版本 ID、字段 ID、生成历史 ID 时返回 403/404，不越权读取或回滚。
- [ ] 重复请求、并发确认、网络重试不产生重复版本或重复产品；失败后可安全重试。
- [ ] 删除/停用/回滚等破坏性操作必须有鉴权和二次确认，错误输入不能部分执行。

## 10. UI 与性能回归

- [ ] 1366×768、1920×1080、浏览器缩放 100%/125% 下，字段管理、导入预览、版本差异、型号多选和生成结果无横向溢出或遮挡。
- [ ] 动态字段很多时表格支持横向滚动/列配置；长参数折叠或详情展示，不撑破页面。
- [ ] 上传大文件时显示进度或处理中状态，按钮防重复；解析不阻塞页面交互。
- [ ] 资料库列表具备搜索、品类筛选、启用状态筛选、分页；不会一次渲染全部历史版本。
- [ ] 文案生成中有加载、失败、空结果、重试和复制反馈；切换页面/型号时不会显示上一型号结果。
- [ ] 50 字、多型号、过期政策和缺失参数的提示样式与现有系统一致，弹层不跑出视口。
- [ ] 至少用 1000 条产品资料、100 个自定义字段和 10 个版本进行本地测试，记录首屏、预览和查询耗时；无明显卡顿。

## 12. 放行标准

以下任一项不满足，不得部署生产：

1. TV/显示器或渠道隔离失败。
2. 合并更新与完整覆盖语义混淆，或导入出现半批数据。
3. 版本回滚不能恢复活动版本，或历史生成被篡改。
4. 过期政策进入文案，或缺失资料被 AI 编造。
5. 多型号文案出现参数串线，50 字选项无效。
6. 未登录/越权请求可读写资料、字段、版本或生成记录。
7. `pnpm build`、`git diff --check` 或专项回归失败且无明确豁免。

外部京东/B站登录、同步和真实私信不属于本地回归；若必须验证，应另行授权并单独记录，不得以“未执行”写成通过。
